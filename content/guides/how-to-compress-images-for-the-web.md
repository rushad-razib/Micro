## When to compress

Stub. Compress when a photo is larger than it needs to be for a page. Unique copy ships in Phase B.

## How to do it here

Open the [compress image](/compress-image) tool. The file stays in your browser.

## Quality

A typical starting point is JPEG or WebP quality 80. Results vary. There is no guaranteed percentage saving.

## Formats

Use [convert image](/convert-image) if you need a different format after you compress.
