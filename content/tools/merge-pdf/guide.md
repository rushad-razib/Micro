## How merge works

This tool reads each PDF you add in the browser and builds a single document with pdf-lib. Pages appear in the order of the files you selected. Nothing is sent to a server.

## Default result

Every page from every input file is included. The download is named with a `merged` suffix so you can tell it apart from the originals.

## How to use it

Add two or more PDFs with browse or drop. Check the file list order, then download. If you need only some pages from a source file, [split PDF](/split-pdf) first, then merge the pieces you want.

## Limits

About 50 MB total, 20 files, and 200 pages across all inputs. Password-protected or damaged PDFs are rejected with a plain error.
