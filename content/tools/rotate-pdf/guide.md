## How rotation works

Each page’s rotation flag is updated in the browser and written into a new PDF. Your original file on disk is unchanged until you save the download.

## Default result

All pages rotate 90° clockwise. Switch to 180° or 270° before download when that fits the scan better.

## How to use it

Drop a PDF, pick the angle, and download. Combine with [split PDF](/split-pdf) if only part of the document should turn.

## Limits

About 50 MB and 200 pages. Password-protected files are not supported here.
