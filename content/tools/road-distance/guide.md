## What this measures

Stand at the start, walk the alignment, and stand at the end. The straight line is the distance between those two marks. The walked path is the length of the track recorded while you walk. Use the walked path when the alignment bends. The straight line is shorter whenever the line bends.

The road does not need to exist on a map. The track is not snapped to a road.

## How to measure

Use a phone outdoors, with this page open and the screen on. A phone stops location updates when the page is in the background.

Stand on the start and tap Mark start. Hold still until the button is ready, then tap it again. Walk the alignment. At the end, hold still until Mark end is ready, then tap it.

A fix worse than 10 meters is ignored. Each mark needs five good fixes in a row, all within 5 meters of each other. While you walk, a point is kept only after you move at least 5 meters, and only when that step is no faster than a walk. A jump is dropped so it does not add a false length.

## How to read the result

Both lengths are whole meters. The ± figure is the phone’s estimate, not a survey tolerance. The walked length can still be long if the fix wanders, or short if a bend was sampled sparsely. The plot is north-up and uses only the positions already on this phone. Download the record if you need the coordinates. The file stays on this device.

## What this does not do

This is not a survey. A few meters of error is common. Do not use it as the only figure on an official requirement.
