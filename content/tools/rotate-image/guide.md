## How this tool handles your image

Rotation and flips are applied by transforming the canvas in your browser. Each click updates the preview; you can combine a 90° turn with a horizontal or vertical flip. The source file never leaves your device.

## Default result

Opening a file shows the original orientation. You do not have to rotate to download—useful when you only wanted to check how a flip would look.

Four consecutive 90° rotations in the same direction return the image to its starting angle. The download filename includes the `rotated` suffix when you save after changes.

## How to use it

Load JPEG, PNG, WebP, or a GIF’s first frame. Use the left and right rotate buttons for quarter turns, or flip controls for mirror effects. Download when the preview is correct.

If the composition still feels off, follow with [crop image](/crop-image) or [resize image](/resize-image).

## Limits

25 MB maximum file size and 8192 pixels on the longest edge. Processing is local only—no server upload.
