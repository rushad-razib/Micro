## How this tool handles your image

Stub. Covers the Instagram feed frame, then center-crops to 1080×1350.

## Default result

Stub. 1080×1350. Story size is a chip on this page, not a separate URL.

## How to use it

Drop a file. Switch to story if you need 1080×1920. For free dimensions use [resize image](/resize-image).

## Limits

25 MB and 8192 pixels on a side. The file is not uploaded.
