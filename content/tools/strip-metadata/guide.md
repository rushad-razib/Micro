## How this tool handles your image

Stub. Reads EXIF on the device, then re-encodes the pixels so metadata is dropped.

## Default result

Stub. Same pixel size. JPEG and WebP use high quality. See [what EXIF data reveals](/guides/what-exif-data-reveals).

## How to use it

Drop a file. The page lists camera, date, software, and whether location is embedded.

## Limits

25 MB and 8192 pixels on a side. The file is not uploaded.
