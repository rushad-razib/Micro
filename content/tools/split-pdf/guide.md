## How split works

The tool opens your PDF in the browser, copies the pages in your chosen range into a new document, and offers a download. The original file is not modified on disk.

## Default result

The full page range is selected (first page through last). Change the start and end fields when you only need a chapter or attachment.

## How to use it

Drop one PDF, set the page range if needed, and download. To combine extracts from several files, use [merge PDF](/merge-pdf) afterward.

## Limits

Files up to about 50 MB and 200 pages. Encrypted PDFs are not supported in this release.
