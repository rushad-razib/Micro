## How this tool handles your image

Resize redraws your photo on an HTML canvas in the browser. You can set exact width and height, scale by percent, or cap the longest edge while keeping aspect ratio. The original file is not uploaded anywhere.

JPEG, PNG, WebP, and GIF (first frame only) are supported as inputs.

## Default result

The tool fits your image inside a 1920×1920 box without stretching. Smaller photos are left at their native size—we do not upscale by default, which avoids blurry enlargements.

Output format follows sensible defaults for the source type. The download name uses the `resized` suffix.

## How to use it

Add a file by drag-and-drop, paste, or browse. Use the controls to switch between max edge, fixed pixels, or percentage. When dimensions look right, download the result.

Platform-specific frames live on dedicated pages—[Instagram](/resize-image-for-instagram), [YouTube](/youtube-thumbnail-resizer), [Facebook](/resize-image-for-facebook), and [LinkedIn](/resize-image-for-linkedin)—if you need exact social sizes instead of a custom box.

## Limits

Maximum file size is 25 MB and maximum edge length is 8192 pixels. Processing stays entirely in your browser.
