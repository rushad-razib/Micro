## How this tool handles your image

Stub. Scales the bitmap in the browser and keeps aspect ratio by default.

## Default result

Stub. Fit inside 1920×1920. Does not upscale.

## How to use it

Drop a file. Change width, height, percent, or max edge if you need something else.

## Limits

25 MB and 8192 pixels on a side. The file is not uploaded.
