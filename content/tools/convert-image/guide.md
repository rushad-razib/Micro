## How this tool handles your image

Stub. Re-encodes the bitmap to JPEG, PNG, or WebP in the browser.

## Default result

Stub. Non-WebP files become WebP. WebP files become JPEG.

## How to use it

Drop a file. Pick another format if you need it. See the [WebP vs JPEG](/guides/webp-vs-jpeg) guide.

## Limits

25 MB and 8192 pixels on a side. The file is not uploaded.
