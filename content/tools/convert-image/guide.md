## How this tool handles your image

Convert re-encodes your picture to JPEG, PNG, or WebP using the browser’s canvas pipeline. Pixels are read once on your device and written out in the format you choose. We do not store or transmit the file.

When the browser supports AVIF encoding, that option may appear; otherwise stick to WebP or JPEG for broad compatibility.

## Default result

Most uploads become WebP, which often yields a smaller file at similar visual quality. If you already opened a WebP, the default target switches to JPEG so you are not stuck in a loop.

Quality follows the same sensible defaults as our other canvas tools. Downloads use the `converted` suffix.

## How to use it

Drop or pick a file, then select the output format if the default is not what you need. Download when ready.

Not sure which format to pick? Read [WebP vs JPEG](/guides/webp-vs-jpeg) for a plain-language comparison, then [compress image](/compress-image) if you need to shrink the converted file further.

## Limits

25 MB and 8192 pixels per side are the caps. All conversion happens in your browser without an upload.
