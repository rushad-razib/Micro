## How images become a PDF

Each image is placed on its own page and scaled to fit while keeping aspect ratio. Encoding runs in the browser with pdf-lib. Files are not uploaded.

## Default result

Pages follow the order you added the images. The download uses an `images` suffix.

## How to use it

Add one or more photos, confirm the list, and download. For smaller inputs first, use [compress image](/compress-image) or [resize image](/resize-image).

## Limits

About 50 MB total, 30 images, and 8192 pixels on the longest edge per image.
